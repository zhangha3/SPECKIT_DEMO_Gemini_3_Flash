# Quickstart: 001-shipping-port-lookup

## 开发环境搭建

1. **安装依赖**
   ```bash
   npm install
   ```

2. **本地调试**
   ```bash
   npm run dev
   ```

3. **运行测试**
   ```bash
   npm run test
   ```

## 核心工作流
- 修改 `src/assets/ports.json` 来增加港口数据。
- 搜索逻辑位于 `src/composables/usePorts.ts`。
- UI 样式采用 Tailwind CSS，配置文件为 `tailwind.config.js`。
